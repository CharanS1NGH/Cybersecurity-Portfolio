# Packet Tracer Network Design

This project demonstrates network design and configuration using Cisco Packet Tracer.

## Skills Demonstrated
- VLAN Configuration
- IPv4 Addressing
- IPv6 Addressing
- DHCP
- DNS
- Router Configuration
- Switch Configuration
- Network Troubleshooting

## Tools Used
- Cisco Packet Tracer

## What I Learned
This project helped me develop practical networking skills including device configuration, connectivity testing and troubleshooting.
